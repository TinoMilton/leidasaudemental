# Google AdSense Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add env-gated Google AdSense ad slots (blog post, blog list, landing page), plus the review prerequisites (privacy policy page, ads.txt, verification meta tag, Consent Mode v2 defaults).

**Architecture:** A single config module (`src/lib/adsense.ts`) reads `VITE_ADSENSE_*` env vars and lazily injects the AdSense script. A reusable `<AdSlot>` component renders `<ins class="adsbygoogle">` only when both client and slot IDs exist, so the site ships with ads fully inert until env vars are set in Cloudflare Pages. The blog markdown parser moves to `src/lib/markdown.tsx` and gains a `beforeH2` hook used to inject in-article ads.

**Tech Stack:** Vite 5, React 18, TypeScript, Tailwind, react-router-dom 6, Vitest 2 (added for the parser test).

**Spec:** `docs/superpowers/specs/2026-10-25-adsense-design.md`

**Branch:** `feat/adsense` (already created)

```ts
const env = import.meta.env;

export const adsenseClient: string | undefined = env.VITE_ADSENSE_CLIENT || undefined;

export const adSlots = {
  blogInArticle: env.VITE_ADSENSE_SLOT_BLOG_INARTICLE || undefined,
  blogFooter: env.VITE_ADSENSE_SLOT_BLOG_FOOTER || undefined,
  blogList: env.VITE_ADSENSE_SLOT_BLOG_LIST || undefined,
  home: env.VITE_ADSENSE_SLOT_HOME || undefined,
} as const;

const SCRIPT_ID = 'adsbygoogle-js';

/** Injects the AdSense script once. No-op when VITE_ADSENSE_CLIENT is not set. */
export function loadAdSense() {
  if (!adsenseClient || document.getElementById(SCRIPT_ID)) return;

  const script = document.createElement('script');
  script.id = SCRIPT_ID;
  script.async = true;
  script.crossOrigin = 'anonymous';
  script.src = `https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=${adsenseClient}`;
  document.head.appendChild(script);
}
```

### Task 3: `<AdSlot>` component

**Files:**
- Create: `src/components/AdSlot.tsx`

- [ ] **Step 1: Create the component**

```tsx
import { useEffect, useRef } from 'react';
import { cn } from '@/lib/utils';
import { adsenseClient } from '@/lib/adsense';

interface AdSlotProps {
  slot?: string;
  format?: 'auto' | 'fluid';
  layout?: 'in-article';
  className?: string;
}

export function AdSlot({ slot, format = 'auto', layout, className }: AdSlotProps) {
  const pushed = useRef(false);
  const enabled = Boolean(adsenseClient && slot);

  useEffect(() => {
    if (!enabled || pushed.current) return;
    pushed.current = true;
    try {
      (window.adsbygoogle = window.adsbygoogle || []).push({});
    } catch (error) {
      console.warn('[AdSlot] adsbygoogle.push failed', error);
    }
  }, [enabled]);

  if (!enabled) return null;

  return (
    <aside aria-label="Publicidade" className={cn('my-10 text-center', className)}>
      <span className="block text-xs uppercase tracking-wider text-[#9CA3AF] mb-2">
        Publicidade
      </span>
      <ins
        className={cn('adsbygoogle', format === 'fluid' ? 'min-h-[200px]' : 'min-h-[280px]')}
        style={{ display: 'block' }}
        data-ad-client={adsenseClient}
        data-ad-slot={slot}
        data-ad-format={format}
        data-ad-layout={layout}
        data-full-width-responsive="true"
      />
    </aside>
  );
}
```

Notes for the implementer:
- Do not add green backgrounds/shadows — AdSense forbids styling ads to look like site content.
- `pushed` ref prevents StrictMode's double-invoked effect from pushing twice into the same `<ins>`.

### Task 4: Build-time AdSense verification meta tag

**Files:**
- Modify: `vite.config.ts`

- [ ] **Step 1: Replace `vite.config.ts`**

```ts
import { defineConfig, loadEnv, type Plugin } from "vite";
import react from "@vitejs/plugin-react-swc";
import path from "path";
import { componentTagger } from "lovable-tagger";

// Adds <meta name="google-adsense-account"> so AdSense can verify the site from static HTML
function adsenseVerification(client?: string): Plugin {
  return {
    name: "adsense-verification",
    transformIndexHtml() {
      if (!client) return [];
      return [
        {
          tag: "meta",
          attrs: { name: "google-adsense-account", content: client },
          injectTo: "head",
        },
      ];
    },
  };
}

// https://vitejs.dev/config/
export default defineConfig(({ mode }) => {
  const env = loadEnv(mode, process.cwd(), "VITE_");

  return {
    server: {
      host: "::",
      port: 8080,
    },
    plugins: [
      react(),
      mode === 'development' &&
      componentTagger(),
      adsenseVerification(env.VITE_ADSENSE_CLIENT),
    ].filter(Boolean),
    resolve: {
      alias: {
        "@": path.resolve(__dirname, "./src"),
      },
    },
  };
});
```

`loadEnv` merges `.env*` files with `process.env`, so Cloudflare Pages build variables are picked up.
